# 💡 AI-Powered Smart Home Automation

## Project Overview
An AI-powered Smart Home Automation system that allows users to control a bulb using natural-language commands.

## Technologies Used
- n8n – Workflow Automation
- Groq – AI Chat Model
- ThingSpeak – IoT Cloud Platform
- ESP32 – Microcontroller
- HTTP Request – API Integration

## Key Features
- Turn ON/OFF the bulb using natural-language commands.
- Control devices through an AI Agent.
- Check the current bulb status.
- Connect AI workflows with IoT devices.

## How It Works
1. User sends a command through chat.
2. AI Agent understands the command.
3. n8n processes the workflow.
4. ThingSpeak communicates with the IoT system.
5. ESP32 controls the bulb through a relay.
